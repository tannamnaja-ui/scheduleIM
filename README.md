# ระบบสรุปตารางทีมติดตั้ง (ดูอย่างเดียว)

ดึงข้อมูลจาก Google Sheet ทุกแท็บรายเดือน (ชื่อแท็บแบบ `ตค 2569`, `พย 2569`, …) โดยอ่าน merged cell และสีของแต่ละไซต์

## วิธีใช้
- ดับเบิลคลิก `start.bat` หรือรัน `node server.js` (ต้องมี Node.js 18 ขึ้นไป) แล้วเปิด http://localhost:4000
- ข้อมูลรีเฟรชอัตโนมัติทุก 5 นาที หรือกดปุ่ม "อัปเดตข้อมูล"
- ถ้าเชื่อมต่อ Google ไม่ได้ ระบบจะใช้ข้อมูลล่าสุดใน `data-cache.json`

## หน้าจอ
1. **รายบุคคล / ค้นหาตามวันที่** – ค้นหาชื่อ/ชื่อเล่น ดูปฏิทินและช่วงเวลาที่อยู่แต่ละไซต์ เลือกวันที่เพื่อดูว่าทุกคนอยู่ที่ไหน
2. **ภาพรวมทุกคน** – ตารางแบบ Google Sheet เลือกเดือนหรือดูทุกเดือนต่อกัน ย่อ/ขยาย และเต็มหน้าจอ
3. **สรุปรายไซต์** – แต่ละไซต์มีใครบ้าง เข้าไซต์วันแรกวันที่เท่าไหร่ วันสุดท้าย จำนวนวัน

ตั้งค่าได้ด้วยตัวแปรแวดล้อม `PORT` และ `SHEET_ID`
