# ระบบสรุปตารางทีมติดตั้ง (ดูอย่างเดียว)

ดึงข้อมูลจาก Google Sheet ทุกแท็บรายเดือน (ชื่อแท็บแบบ `ตค 2569`, `พย 2569`, …) โดยอ่าน merged cell และสีของแต่ละไซต์

## เว็บออนไลน์ (GitHub Pages)
- https://tannamnaja-ui.github.io/scheduleIM/
- GitHub Actions ([.github/workflows/pages.yml](.github/workflows/pages.yml)) ดึงข้อมูลจาก Google Sheet ทุก 15 นาที และทุกครั้งที่ push แล้วสร้าง `data.json` ให้หน้าเว็บ
- สั่งอัปเดตทันทีได้ที่แท็บ Actions → Deploy to GitHub Pages → Run workflow

## อัปเดตอัตโนมัติเมื่อแก้ Google Sheet (ภายใน ~1 นาที)
1. เปิด https://script.google.com → **New project** → วางโค้ดจาก [apps-script/Code.gs](apps-script/Code.gs) → Save
2. **Deploy → New deployment** → เลือกประเภท **Web app** → Execute as: **Me**, Who has access: **Anyone** → Deploy → อนุญาตสิทธิ์
3. คัดลอก Web app URL (ลงท้าย `/exec`) ใส่ใน [public/config.js](public/config.js) แล้ว push

แอปจะดึงข้อมูลสดทุก 1 นาทีและทุกครั้งที่กลับมาเปิดแอป ถ้า Apps Script ใช้ไม่ได้จะใช้ `data.json` จาก GitHub Actions แทนอัตโนมัติ

## ติดตั้งเป็นแอปบนมือถือ (PWA)
- **Android (Chrome):** เปิดลิงก์ด้านบน → แตะปุ่ม ⬇ มุมขวาบน หรือเมนู ⋮ → *ติดตั้งแอป / เพิ่มลงในหน้าจอหลัก*
- **iPhone/iPad (Safari):** เปิดลิงก์ → ปุ่มแชร์ ⬆ → *เพิ่มไปยังหน้าจอโฮม*
- เปิดแบบเต็มจอเหมือนแอป มีเมนูด้านล่าง และเปิดได้แม้ออฟไลน์ (ใช้ข้อมูลล่าสุดที่เคยโหลด)

## วิธีใช้ในเครื่อง (ข้อมูลสดทุกครั้งที่กดอัปเดต)
- ดับเบิลคลิก `start.bat` หรือรัน `node server.js` (ต้องมี Node.js 18 ขึ้นไป) แล้วเปิด http://localhost:4000
- ข้อมูลรีเฟรชอัตโนมัติทุก 5 นาที หรือกดปุ่ม "อัปเดตข้อมูล"
- ถ้าเชื่อมต่อ Google ไม่ได้ ระบบจะใช้ข้อมูลล่าสุดใน `data-cache.json`

## หน้าจอ
1. **รายบุคคล / ค้นหาตามวันที่** – ค้นหาชื่อ/ชื่อเล่น ดูปฏิทินและช่วงเวลาที่อยู่แต่ละไซต์ เลือกวันที่เพื่อดูว่าทุกคนอยู่ที่ไหน
2. **ภาพรวมทุกคน** – ตารางแบบ Google Sheet เลือกเดือนหรือดูทุกเดือนต่อกัน ย่อ/ขยาย และเต็มหน้าจอ
3. **สรุปรายไซต์** – แต่ละไซต์มีใครบ้าง เข้าไซต์วันแรกวันที่เท่าไหร่ วันสุดท้าย จำนวนวัน

ตั้งค่าได้ด้วยตัวแปรแวดล้อม `PORT` และ `SHEET_ID`
